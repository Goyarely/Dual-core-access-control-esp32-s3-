03设计令牌（可直接翻译为代码）

所有视觉参数收敛为四张表。实现时集中定义在 ui_theme.h，任何界面不得出现字面色值——保证后续调主题只改一处。

色彩令牌

令牌值用途
预览底0x0D1420摄像头预览区背景
成功0x1E8E4F通行成功整屏 / 结果 chip
拒绝0xC4322A拒绝整屏 / 失败点阵
锁定0xB26A00锁定屏 / 警示
品牌0x185FA5菜单头 / 进度条 / 主按钮
检测框0x4CE08A人脸角框 / 扫描线
信息卡0xFFFFFF信息卡 / 浅色屏底 #F4F6F9
文字主0x1C2330标题 / 正文（次 #5C6675）

字体与布局

项规范说明
正文字库思源黑体 16px（现有）全 UI 默认
结果大字新增 32px 子集字库仅姓名/常用词 ~40 字，约 40KB；LVGL 不支持位图缩放
信息卡标题16px / 600每屏唯一焦点
辅助文字12px / #5C6675说明行
圆角信息卡 16 / 列表项 12 / 芯片 999lv_obj_style radius
间距4 的倍数：8 / 12 / 16 / 24信息卡内边距 14–16
状态栏高 30px，时间左 / 锁态右深色屏用反白，浅色屏用主文字色
户外可读性约束：结果页整屏铺色 + 26px 大字，保证 1.5m 外可读；信息卡白底黑字对比度 > 7:1；禁用细字重（IPS 屏低灰阶发虚）。

04动效规范

全部动效收敛为 5 个，时长与缓动固定。LVGL 侧统一用 lv_anim / lv_scr_load_anim 实现，禁止各界面自定义时长。

动效参数LVGL 实现
界面切换200ms 淡入（无位移）lv_scr_load_anim(scr, LV_SCR_LOAD_ANIM_FADE_IN, 200, 0, true)
成功勾描画300ms · 延迟 150ms · ease-outlv_line + lv_anim_path_ease_out 改 line_points，或预渲染 5 帧序列
角框脉冲 / 扫描线1.2s / 1.4s · 无限循环lv_anim 设 LV_ANIM_REPEAT_INFINITE 改 opacity/y
呼吸 LED / 倒计时条2s 循环 / 线性推进lv_anim 改 opacity / lv_bar set_value + lv_timer
toast 提示250ms 淡入 · 1.8s 后淡出lv_obj + opacity anim + lv_timer 回收

05界面 → LVGL 控件映射与状态机接线

控件映射

元素LVGL 控件
摄像头预览lv_canvas（GC0308 帧拷贝，双缓冲，常驻不销毁）
人脸角框4 × lv_line 叠加 canvas，改坐标跟踪框
状态栏3 × lv_label + 顶栏 lv_obj（h=30）
信息卡lv_obj（radius 16）+ lv_label
进度 / 倒计时lv_bar（挑战/录入）、lv_arc（落锁 2s）
菜单 / 列表lv_list + lv_btn
通行记录lv_table（2 列，chip 用 cell 样式着色）
抓拍缩略图lv_img（GC0308 BMP 缩放 96×72，RAM 缓存）

状态机 → 界面接线

事件 / 状态目标界面
IDLE（无触摸 5s）① 待机
DET stable ×3② 识别中
识别命中 → 挑战开始③ 活体挑战
GRANTED（UNLOCK_ACK）④ 成功 → 2s 后回 ①
DENIED（原因 / fail_count）⑤ 拒绝 → 2.6s 后回 ①
DOOR_LOCKOUT⑥ 锁定（GD32 计时经 STATE 帧同步）
长按 800ms + 管理验证⑦ 菜单 → ⑧ 录入 / ⑨ 记录
链路故障（心跳 3 次丢失）信息卡黄条提示，界面不切换
性能约束：预览 canvas 拷贝与识别推理分属核 0 / 核 1，UI 每帧 LVGL 锁内工作 < 5ms（超时打印告警）；界面切换只改信息卡内容与 canvas 叠加层，预览层零重建。
UI 2.0 相对 v1 的变更

① 设计令牌化，色值/字号/动效全部有规范且映射到 LVGL API；② 预览/信息分层版式替代整屏深色；③ 结果页补抓拍留证与失败点阵；④ 新增通行记录页（lv_table）；⑤ 大字 32px 子集字库方案；⑥ 交互原型带状态机与固件格式日志，可直接用于演示彩排。
